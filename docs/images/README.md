# 截图目录

README 里展示的界面截图放在这里，使用**相对路径**引用（`docs/images/01-overview.png`），
因此 GitHub、本地编辑器、别人 clone 后都能正常显示，不依赖任何外部图床。

建议的文件名与内容：

| 文件 | 内容 |
| --- | --- |
| `01-overview.png` | 主界面全屏：左侧卡片列表 + 中间正文 + 右侧预览 |
| `02-card.png` | 卡片详情或悬停关键词弹出的预览 |
| `03-map.png` | 地图：标记点与多边形区域 |
| `04-timeline.png` | 时间轴：泳道、条目、纪元 |
| `05-outline.png` | 大纲树 + 正文，或文档导出对话框 |

约定：

- 截图统一用示例世界观「灰烬纪元」，不要用作者本人的真实作品（会公开）。
- 窗口最大化后再截；GitHub 会按 README 宽度缩放显示，小窗口截图会糊。
- 单张控制在 1 MB 以内（一般 1400px 宽的 PNG 约 200～400 KB），避免仓库体积膨胀。
- 新增截图时文件名按序号往后排，README 里对应位置的引用同步更新。
