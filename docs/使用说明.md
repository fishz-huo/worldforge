## 0 安装与启动

### 0.1 桌面版（Windows 桌面应用，推荐）

需要先装 Node.js 与 Rust 工具链。

```cmd
cd /d E:\newworlde
npm install
npm run tauri:dev
```

启动后会弹出一个 1360×880 的应用窗口。想打成安装包给别人用：`npm run tauri:build`，产物在 `src-tauri/target/release/bundle/`。

### 0.2 浏览器 / 手机 / 平板

```cmd
npm run dev        # 打开 http://localhost:5173
```

手机与平板用同一局域网访问终端里打印的 `Network` 地址即可；在浏览器菜单里选「添加到主屏幕 / 安装应用」，就能像 App 一样离线使用。

> 本软件**不联网、不上传、不需要账号**：所有数据只存在你这台机器的浏览器数据库（IndexedDB）里。

### 0.3 首次启动发生了什么

第一次打开会自动写入一个示例世界观 **「灰烬纪元」**，里面已经有：8 张卡片、若干关联与标签、1 张地图（含 2 个资源区域）、1 条时间轴（含 5 条泳道与 12 个条目）、1 篇正文与 1 篇大纲。

你可以直接在示例上改，也可以随时推倒重来：[设置 → 数据 → 危险操作](#126-危险操作不可撤销) 里的「重建示例世界观」或「清空全部数据」。

### 0.4 第一次用，建议按这个顺序走一遍

1. **认识卡片**：按 `2` 进卡片 Wiki，点示例卡片「烬·阿舒尔」，看右侧检查器里的关联与反向引用（[§4](#4-卡片-wiki)）。
2. **写一段正文并挂上设定**：按 `5` 进写作，在正文里输入 `[[`，选一张卡片回车（[§7](#7-写作)）。
3. **看一眼时间与地图**：按 `4` 拖动时间轴游标看当年发生了什么，按 `3` 看地图标记（[§6](#6-时间轴)、[§5](#5-地图)）。

### 0.5 想拿真实数据试每个功能：用「猫猫的冒险」

示例世界观只有 8 张卡片，够认识界面，但不够把所有功能喂满（比如标签筛选、双链缺口、资源热度对比都需要更多数据）。另一套**测试世界观「猫猫的冒险」**专为这件事准备：

- 手册：[`docs/猫猫的冒险·世界观设定.txt`](猫猫的冒险·世界观设定.txt) —— 纯文本，把 48 张卡片（9 种类型都有）、7 个标签、16 条关联、2 张地图、12 个标记点、4 个多边形区域、5 条泳道、16 个时间轴条目、4 个纪元、3 篇文稿、13 个大纲节点、3 条平行世界分支逐条写好，照着抄即可。
- 想省事就导入：[设置 → 数据 → 导入设定](#124-导入) 选择 `samples/猫猫的冒险.worldforge.json`。
  ⚠️ 导入会**覆盖当前世界观的全部内容**，所以先在世界观切换器里[新建一个空世界观](#21-新建切换删除世界观)，切过去再导入；原来的「灰烬纪元」不受影响。
- 手册第【十、功能核对清单】按 12 个模块列了勾选项，建完之后照着点一遍就知道每个功能有没有数据可看。
- 手册里故意留了 11 处指向未创建卡片的 `[[双链]]`：它们会显示成"尚未创建"的样式，用来验证双链的缺口提示，不是数据错误。

## 1 界面总览与通用操作

### 1.1 屏幕被分成五块

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| **顶栏** | 最上方（高 44px） | 软件名与版本、当前模块名、全局搜索框、分支口径开关、面板显隐、专注模式、主题切换、命令面板 |
| **图标导航栏** | 最左的细竖条 | 9 个模块图标 + 「收起导航栏」+ 世界观切换器 |
| **次级侧栏** | 导航栏右侧（宽 256px） | 当前模块的列表 / 筛选 / 新建入口；标题栏右侧有「收起侧栏 (Ctrl+B)」 |
| **主内容区** | 中间，自动占满剩余宽度 | 当前模块的主体界面 |
| **右侧检查器** | 最右（宽 320px） | 选中对象的属性、反向引用、编辑表单；可折叠区块「标签」「结构化字段」「关联关系」等 |
| **底部状态栏** | 最下方（高 24px） | 保存状态、卡片数、关联数、地图数、当前世界观 / 分支 |

### 1.2 顶栏上每个按钮干什么

从左到右：

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| `WorldForge v0.1` + 模块名 | 最左 | 只作标识；模块名后面那行小字是当前模块的说明 |
| 搜索框（占位字「搜索标题 / 摘要 / 正文 / 字段…」） | 中部 | 全局搜索：在**卡片库**里筛卡片，在**时间轴 / 大纲 / 版本**里筛条目。输入即生效，右侧出现 `×` 可一键清空 |
| `当前分支` / `全部分支` | 搜索框右侧 | 切换「只看当前世界线」与「把各条平行世界的设定一起看」（见 §2.5） |
| 侧栏图标（提示「侧栏 (Ctrl+B)」） | 右起第 5 个 | 显示 / 隐藏次级侧栏；图标变淡表示已收起 |
| 检查器图标（提示「检查器 (Ctrl+I)」） | 右起第 4 个 | 显示 / 隐藏右侧检查器 |
| 专注模式图标（提示「专注模式 (Ctrl+\)」） | 右起第 3 个 | 一键收起导航栏 + 侧栏 + 检查器 + 状态栏，只剩内容区；再点一次按原样恢复 |
| 月亮 / 太阳图标（提示「切换到暗色 / 切换到亮色」） | 右起第 2 个 | 明暗主题互换 |
| 终端图标（提示「命令面板 (Ctrl+K)」） | 最右 | 打开命令面板 |

> 搜索框在**总览 / 插件 / 设置**三个模块里自动隐藏（那里没有可筛的列表）。
> 布局与主题这些「界面偏好」记在浏览器 localStorage 里，换世界观不受影响，下次打开还是你上次的样子。

### 1.3 底部状态栏在看什么

| 显示 | 含义 |
| --- | --- |
| `本地优先 · 数据仅存于本机` / `正在写入本地…` / `已保存 · 3 分钟前` / `保存失败：…` | 保存状态，逐字如实反映（见 [§12.1](#121-自动保存是怎么工作的)） |
| `卡片 N`、`关联 N`、`地图 N` | 当前视野下的数据规模（窄屏会自动只留前两项） |
| 最右侧 `世界观名 / 分支名` | 当前所处的位置；主世界显示为 `灰烬纪元 / 主世界` |

### 1.4 收起与展开：让界面只剩内容

- 收起**导航栏**：点竖条底部的 `‹`（提示「收起导航栏」）；收起后竖条只剩一个 `›`（提示「展开导航栏」）。
- 收起**侧栏** / **检查器**：点各自标题栏右上角的收起图标，或用 `⌨ Ctrl+B` / `⌨ Ctrl+I`。
- **专注模式**：`⌨ Ctrl+\` 或顶栏的专注图标。三栏 + 状态栏一起收起；退出时恢复到进入前的布局。
- 这些都是持久化偏好，下次启动保持原样。

### 1.5 命令面板（`⌨ Ctrl+K`）：两步之内到达任何地方

1. 按 `⌨ Ctrl+K`（或点顶栏最右的终端图标）→ 弹出命令面板，光标已在输入框里。
2. 输入关键词（占位字「搜索命令、卡片、文稿…」）→ 列表实时过滤，按分组显示：

| 分组 | 里面有什么 |
| --- | --- |
| `导航` | `前往「总览」`、`前往「卡片 Wiki」`…9 个模块 |
| `动作` | `新建卡片`、`新建正文文稿`、`新建大纲`、`保存设定快照`、`立即保存到本地`、`切换专注模式` |
| `插件命令` | 各插件注册的命令（内置如 `配色插件：如何切换主题`、`生成一个人名`、`图库灯箱：预览当前页面第一张图`） |
| `卡片` | 当前世界观的全部卡片（最多 400 条），选中即跳转并打开该卡 |
| `文稿` | 正文 / 大纲 / 笔记，选中即跳转 |

3. `↑` `↓` 选择 → `Enter` 执行 → `Esc` 关闭。底部常驻提示：`↑↓ 选择`、`Enter 执行`、`Esc 关闭`。

### 1.6 全部快捷键

软件内也有一份同样的表：**设置 → 关于 → 快捷键**。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl / Cmd + K` | 打开命令面板 |
| `Ctrl / Cmd + S` | 立即保存到本地（右下角提示「已保存到本地」） |
| `Ctrl / Cmd + B` | 显示 / 隐藏次级侧栏；**在编辑器里则是加粗** |
| `Ctrl / Cmd + I` | 显示 / 隐藏右侧检查器 |
| `Ctrl / Cmd + \` | 专注模式（三栏全收起） |
| `1` – `9` | 直接切换到对应模块（见下表） |
| `Esc` | 关闭浮层、清空搜索；在编辑器里关闭 `[[` 候选框 |
| `[[` | 在编辑器里唤起卡片引用选择器 |
| `Enter` / `Tab` | 在 `[[` 候选框里插入第一条匹配 |

数字键与模块的对应关系：

| 键 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 模块 | 总览 | 卡片 Wiki | 地图 | 时间轴 | 写作 | 大纲 | 版本 | 插件 | 设置 |

> 无修饰键的单键快捷键在输入框里不会触发，所以打字时不会误切模块。

### 1.7 手机 / 平板上的差异

- 图标导航栏变成**底部标签栏**，9 个模块横排。
- 次级侧栏与右侧检查器变成**从边缘滑出的浮层**（带阴影），点内容区即可继续操作。
- 状态栏里的卡片数、地图数在窄屏自动隐藏，只留保存状态与当前位置。

## 2 世界观与平行世界

### 2.1 新建、切换、删除世界观

**新建**：点左下角的世界观切换器（显示当前世界名，鼠标悬停提示 `灰烬纪元 / 主世界`）→ 在菜单的「世界观体系」分组下点 `新建世界观` → 弹出「新建世界观体系」→「名称」填 `星海纪元`（占位提示「例如：星海纪元」）→ 点 `创建`。

- 新建后会自动切换过去，并提示「已创建世界观「星海纪元」」。
- 一个世界观体系可以包含多条平行世界分支，各自拥有独立的卡片、地图与时间轴。

**切换**：同一个菜单里，点「世界观体系」下任意一个世界名 → 当前世界右侧会出现 `✓`，界面整体切过去。

**改名 / 写简介**：`设置 → 世界观` → 第一个字段「名称」直接改，失焦即保存；下面「一句话简介」会显示在总览页顶部。

**删除**：同一个菜单里点 `删除当前世界观`（红色，仅当有 2 个以上世界观时才出现）→ 确认框「确定删除世界观「X」？其全部卡片、地图与文稿都会被移除。」→ 确定即删除。

### 2.2 新建平行世界分支

1. 打开世界观切换器 → 在「平行世界分支」分组下点 `新建平行世界`。
2. 弹窗「新建平行世界」：填「分支名称」（占位提示「例如：if 线 · 主角未觉醒」）。
3. 「设定说明」里写清这个分支和主世界的差别（占位提示「与主世界的分歧在哪里？例如：第 245 年，烬关之战中主角拒绝点燃灵脉」）。
4. 点 `创建`。

> ⚠️ 创建**不会**自动切到新分支，需要你再打开一次切换器，点该分支名。

**切到「主世界（基准设定）」**：切换器里第一项就是它，点一下即回到基准设定。

### 2.3 从当前分支派生（fork）

想让新分支一开始就带着当前设定、之后再独立演化：

1. 先在切换器里切到要派生的那个分支（主世界也行）。
2. 切换器 → `从当前分支派生` → 填「分支名称」+「分歧点描述」→ `创建`。
3. 弹窗里有一行说明：「派生会把当前分支可见的卡片复制一份到新分支，之后两边可以独立修改，互不影响。」

### 2.4 记录分歧点与分支色

`设置 → 世界观` → 往下找到分支卡片：

| 字段 | 说明 |
| --- | --- |
| 分支名称 | 直接改，失焦保存 |
| `分歧点描述` | 占位提示「与主世界的分歧点，例如：第 245 年，主角拒绝点燃灵脉」 |
| `分歧刻度` | 分歧发生在时间轴的哪个刻度上 |
| `分支色` | 该分支在界面上的标记颜色 |

### 2.5 「当前分支 / 全部分支」开关

顶栏搜索框右边的按钮，两个状态循环切换：

- `当前分支`（默认）：只看当前世界线。主世界的卡片在所有分支都能看到，分支独有的卡片只在它自己的世界线里出现。
- `全部分支`：把各条世界线的设定一起看，适合做「if 线之间对照」。

### 2.6 删除分支

切换器里把鼠标移到分支名那一行 → 行尾出现垃圾桶图标 → 点击 → 确认框「删除分支「X」？该分支独有的卡片会被移除。」

## 3 总览

进入方式：点图标导航栏第一项 `总览`，或按 `1`。这一页回答「我的世界观现在缺什么」。

| 区块 | 内容与操作 |
| --- | --- |
| 顶部 | 世界名 + 简介（没写简介时显示「还没有写简介。可以在「设置 → 世界观」里补充。」）+ 徽标「N 条世界线」+ 按钮 `新建卡片` |
| 四张统计卡 | `卡片`、`地图`、`时间轴条目`、`文稿`；文稿卡下面还有「约 N 字」 |
| `卡片构成` | 按类型统计的条形分布；**点任意一行**会跳到卡片 Wiki 并筛出该类型 |
| `最近编辑` | 最近动过的卡片；点一行直接打开那张卡 |
| `底层逻辑` | 世界观底层规则类卡片的速览；点击进入对应卡片 |
| `待补充（N）` | 没有任何关联的「孤立卡片」，最多列 5 条；点一条打开它，顺手补关联 |
| `建议的下一步` | 6 条静态建议，按顺序做一遍就能把世界观搭起来 |

`新建卡片` 按钮点开是一个类型菜单：分组「内置类型」列出 9 种类型，如果有插件注册了新类型，会多一个分组「插件扩展类型」。点类型名即建卡并跳进详情页。

## 4 卡片 Wiki

卡片是这个世界观的最小知识单元：角色、地点、事件、底层逻辑、势力、物品、概念、参考资料、随笔都是卡片。进入方式：点图标导航栏 `卡片 Wiki` 或按 `2`。

### 4.1 九种内置卡片类型

| 类型 | 标题占位 / 摘要标签 | 结构化字段（分组 → 字段） |
| --- | --- | --- |
| **角色** | 「角色姓名」/ 一句话简介 | 生平 → 出生刻度、死亡刻度、性别、种族、所属势力、身份 / 职业；形象 → 外貌、性格；内核 → 目标 / 动机、能力 / 特长、弱点 / 缺陷 |
| **地点** | 「地点名称」/ 一句话简介 | 地理 → 类型、地形、气候；资源 → 人口、农业（0-100）、矿产（0-100）、其它资源；政区 → 控制势力、地标 |
| **事件** | 「事件名称」/ 一句话概述 | 时间 → 开始刻度、结束刻度、影响范围（个人 / 区域 / 国家 / 世界级）；因果 → 起因、经过、结果 / 影响 |
| **底层逻辑** | 「体系名称，如「灵息」」/ 一句话定义 | 体系 → 类别（魔法 / 超凡体系、修炼 / 等级体系、神系 / 信仰、关键物质 / 能量、世界规则 / 物理法则、社会制度 / 经济、科技树 / 技术水平、其它）、作用范围、来源；规则 → 核心规则、代价 / 限制；影响 → 对世界的影响、演变趋势 |
| **势力** | 「势力名称」/ 一句话简介 | 组织 → 领袖、规模、理念 / 目标、势力范围；时间 → 成立刻度、解散刻度 |
| **物品** | 「物品名称」/ 一句话简介 | 属性 → 稀有度、来源、效果；归属 → 持有者 |
| **概念** | 「概念名称」/ 一句话定义 | 定义 → 领域、别名、详细解释 |
| **参考资料** | 「资料标题」/ 摘要 | 出处 → 资料类型（书籍 / 专著、论文 / 研究、网页 / 文章、影视 / 视频、游戏、神话 / 传说、图片 / 画集、其它）、作者、链接、年份；内容 → 关键摘录、可借鉴点 |
| **随笔** | 「标题」/ 一句话摘要 | 没有额外字段（字段区会提示「该类型没有额外字段，直接写正文即可。」） |

> 字段说明里还藏着用法提示，鼠标停在字段名上能看到，例如「时间轴刻度；用于推算任意时间点的年龄」「留空表示在世」「留空表示瞬时事件」「可与地图区域资源联动统计」。

### 4.2 新建一张卡片（两种路径）

**路径 A：指定类型（推荐）**

1. 点左栏最上方的 `新建卡片` → 展开类型菜单。
2. 在「内置类型」里点 `角色`（或任何类型）。
3. 立刻建出一张标题为「未命名」的卡片，界面自动切到卡片 Wiki 并打开它的详情页。
4. 在「标题」框里改写名字（标题框的占位字就是该类型的提示，如「角色姓名」）。

**路径 B：先建后改类型**

1. 卡片网格末尾有一块虚线方块 `快速新建`，点一下 → 直接建一张「随笔」卡片（若你正在按类型筛选，则建该类型）。
2. 想建空的时候就用网格空态里的 `新建卡片` 按钮。

### 4.3 卡片库左栏：筛选与排序

| 控件 | 作用 |
| --- | --- |
| `新建卡片` | 见上一节 |
| `全部卡片` | 一键取消类型筛选与「仅置顶」 |
| `仅置顶` | 只显示被你置顶（星标）的卡片 |
| `按类型` | 每个类型一行，右侧显示数量；点一行只看该类型，再点一次取消 |
| `按标签（N）` / `按标签` | 标签复选列表；标题右侧的 `清除` 一键清空标签筛选。多个标签是 **AND** 语义（同时具备才显示） |
| 标题右上角的 `X`（提示「清除筛选」） | 一次清空标签、搜索、类型、仅置顶 |

卡片网格的工具行（未选中卡片时显示）：

| 控件 | 作用 |
| --- | --- |
| `共 N 张卡片` / `· 类型筛选` / `· N 个标签` | 当前筛选结果说明 |
| 排序下拉（默认 `最近修改`） | 可切换 `最近修改` / `创建时间` / `标题` / `类型` |
| `每行 2 张` / `每行 3 张` / `每行 4 张` | 网格密度 |
| `快速新建` | 见上一节 |

空结果时：搜索无结果显示「没有匹配的卡片」+「试试更换关键词，或清除标签筛选。」；一张卡都没有时显示「这里还没有卡片」+「卡片是世界观的最小知识单元：角色、地点、事件、底层逻辑、参考资料都可以是卡片。」

### 4.4 卡片详情页

点任意一张卡片瓦片即进入详情页，中栏结构：

| 位置 | 内容 |
| --- | --- |
| 头部 | `返回列表` + 类型徽标（如「角色」） |
| 头部右侧 | 置顶（提示「置顶」/「取消置顶」）、创建副本（提示「创建副本」）、删除卡片（提示「删除卡片」） |
| 左列 | 标题 / 副标题 / 摘要三个输入框，下面是页签 `编辑`｜`预览`，再下面是正文编辑区 |
| 右列 | 三个可折叠区块：`标签`、`结构化字段`（内含页签 `编辑`｜`图库`）、`关联关系`；底部显示「已使用标签 N 个」 |

### 4.5 标题、副标题、摘要

- 标题：占位字随类型变化（如「角色姓名」）。
- 副标题：占位「副标题 / 称号 / 所属」。
- 摘要：占位「一句话简介（会显示在卡片列表与悬浮预览里）」（参考资料类型是「摘要」）。

三个框都是**自动保存**：停止输入约 0.4 秒、或点到别处（失焦）即写入本地。

### 4.6 正文：支持的 Markdown 与工具条

正文是纯文本 Markdown（刻意不引入富文本编辑器，保证软件小巧）。工具条从左到右：

| 按钮（鼠标悬停的提示） | 插入的内容 |
| --- | --- |
| `标题` | 行首插入 `## ` |
| `加粗 (Ctrl+B)` | 把选中文字包成 `**…**`（也可直接按 `⌨ Ctrl+B`） |
| `斜体` | `*…*` |
| `无序列表` | 行首 `- ` |
| `有序列表` | 行首 `1. ` |
| `引用` | 行首 `> ` |
| `行内代码` | `` `…` `` |
| `分隔线` | 插入 `---` |
| `插入链接` | 插入 `[链接文字](https://)` |
| `引用设定卡 [[…]]` | 插入 `[[卡片标题]]` |
| `插入图片（也可直接粘贴 / 拖入）` | 打开文件选择框选图 |

工具条右侧实时显示字数与阅读时长（如 `320 字`、`约 2 分钟`）。

**支持的语法一览**

| 语法 | 写法 | 效果 |
| --- | --- | --- |
| 标题 | `#` ~ `######` | 六级标题 |
| 强调 | `**粗**`、`*斜*`、`~~删除~~`、`==高亮==` | 分别渲染为粗体、斜体、删除线、荧光标记 |
| 列表 | `- 项`、`1. 项`，行首缩进两格即嵌套 | 有序 / 无序，可嵌套 |
| 引用 | `> 文字`，连续多行会合并成一段引用 | 引用块 |
| 代码 | 行内 `` `code` ``；整段用三个反引号包起来 | 行内代码 / 代码块 |
| 表格 | 第二行是 `|---|` 分隔行 | 渲染为表格 |
| 链接 | `[文字](https://…)` | 只允许 `http(s)` / `mailto` / `#` 开头的地址 |
| 图片 | `![说明](asset:资源id)` | 本地图片（粘贴 / 拖入时会自动这样写） |
| 卡片双链 | `[[卡片标题]]` 或 `[[卡片标题\|显示文字]]` | 变成可悬停预览的引用（见下） |
| 分隔线 | `---` | 一条横线 |

**双链与零切换写作**

1. 在正文里输入 `[[` → 右下角弹出候选框，标题是「插入设定卡引用」。
2. 继续输入关键词 → 列表实时过滤（同时匹配标题与摘要）。
3. 按 `⌨ Enter`（或 `Tab`）插入第一条匹配，弹出内容变成 `[[卡片标题]]`；也可以用鼠标点列表里的任意一条。
4. 没有匹配时会显示「没有匹配的卡片」和 `新建「你输入的词」`，点它就以「概念」类型新建这张卡片并插入引用。
5. 插入后的 `[[…]]` 在**预览**页签里会变成带下划线的链接：鼠标悬停 0.1 秒弹出卡片摘要卡（卡内提示「点击打开完整卡片 →」），点一下直接打开那张卡。
6. 正文里只要出现已存在的卡片标题，也会自动变成同样的可悬停链接（代码块、链接、已有双链内部不会重复处理）。

**插入图片**：直接在编辑器里 `⌨ Ctrl+V` 粘贴，或把图片文件拖进编辑区 → 自动存入本地资源库并插入引用，右下角提示「图片已插入并存入本地资源库」。

### 4.7 结构化字段（右列「结构化字段」→ 页签 `编辑`）

字段控件按类型自动渲染：

| 字段种类 | 控件与提示 |
| --- | --- |
| 文本 / 长文本 | 普通输入框 / 多行框 |
| 数值 | 数字输入框 |
| 刻度（如出生刻度） | 数字输入框，占位「数值刻度，可为负」，右侧显示单位（默认「年」） |
| 列表 | 占位「用逗号分隔」（中文逗号也可以） |
| 是 / 否 | 开关 |
| 颜色 | 色块 + 十六进制输入框 |
| 单选 | 下拉框，未选时显示「（未设置）」 |

同样是自动保存（停止输入约 0.4 秒或失焦即写）。

### 4.8 标签

1. 展开右列的 `标签` 区块 → 点标签按钮 → 弹出输入框（占位「搜索或输入新标签后回车」）。
2. 输入关键词：已存在的标签会列出来，点一下即勾选 / 取消；没有同名的会显示 `新建标签「你输入的词」`，点它即创建并勾上。
3. 已选标签在按钮下方以胶囊形式显示，点胶囊上的 `×` 取消。
4. 还没有任何标签时，框里提示「还没有标签，直接输入即可创建」。

标签的用处：卡片库左栏的「按标签（N）」筛选、卡片瓦片上的色点、悬浮预览里的标签行。

### 4.9 关联关系（自由填写的关系名）

1. 展开右列的 `关联关系` 区块。
2. 在输入框里写关系名（占位「关系名称（可自由填写，如「师父」）」）——**完全自由**，也可以从下拉建议里选：师父、徒弟、亲属、挚友、宿敌、效忠于、隶属于、统治、出生于、居住于、参与、导致、引发、参考自、灵感来自、拥有、制造、守护、信仰、对立。
3. 点 `关联` → 弹出「关联到哪张卡片？」→ 在搜索框（占位「搜索卡片标题 / 摘要」）里找目标卡片 → 点它即建立关联（没填关系名时存为「相关」）。
4. 关系按方向分两组显示：`指向（本卡 → 其它）`、`被指向（其它 → 本卡）`。也就是说，关联是**双向可查**的：给角色写上「师父 → 某NPC」，那张 NPC 卡片的「被指向」里就会出现这个角色。
5. 改关系名：直接在关系名上修改（占位「关系名称」）。删除关联：鼠标移到那一行，行尾出现垃圾桶图标，点击即删。
6. 目标卡片被删掉后，那一行显示「（已删除的卡片）」。
7. 一条关联都没有时，区块里提示「还没有关联。试试把角色关联到地点、事件或参考资料。」

### 4.10 图库：给卡片配图

入口：右列 `结构化字段` → 页签 `图库`。标题行显示「共 N 张图 · 悬停可设封面或删除」。

**添加图片**：点 `添加图片`（或在没有图时点虚线块「点击添加角色形象 / 设定图」）→ 选图（可多选）→ 右下角提示「已添加 N 张图片」，缩略图出现在网格里。

**设为封面**：鼠标移到缩略图上 → 底部浮出黑色小条 → 点星形图标（提示「设为封面」）→ 图片左上角出现「封面」角标。再点同一个星形（此时提示「当前封面」）即取消封面。封面会显示在卡片瓦片和悬浮预览上。

**从卡片移除 / 删除图片**：鼠标移到缩略图 → 点垃圾桶（提示「从卡片移除」）→ 图片立刻从卡片移除；紧接着弹出确认框「同时从资源库删除这张图片？」：

- 点 `确定` → 连资源库里的原图一起删掉。
- 点 `取消` → 只从卡片移除，图片仍留在资源库（下次还能被别的卡引用）。

> 图片丢了（比如资源被单独清理）时，缩略图位置显示「图片已丢失」，卡片不会出错。

**点击放大预览**：直接点图库里的任意一张图 → 全屏放大（由内置插件「图库灯箱」提供，详见 [§10.6](#106-图库灯箱点击放大预览)）。

### 4.11 预览页签

点正文上方的 `预览` 页签 → 同一张卡片变成只读的排版视图：顶部显示标题、副标题、摘要，下面是渲染后的正文（双链可悬停、图片正常显示）。预览态不会出现输入框，所以内容紧贴页签下方。

标题为空时预览显示「（无标题）」；正文为空时显示「正文还是空的。」；卡片已被删除时整页显示「卡片不存在或已被删除」。

### 4.12 置顶、创建副本、删除

| 操作 | 怎么做 | 结果 |
| --- | --- | --- |
| 置顶 | 详情页头部的图钉（提示「置顶」/「取消置顶」）；或在卡片瓦片上，鼠标悬停时右上角出现的图钉 | 卡片瓦片显示星标，配合左栏「仅置顶」使用 |
| 创建副本 | 详情页头部的复制图标（提示「创建副本」） | 生成一张标题为「原标题 副本」的新卡，标签一并复制，并自动打开 |
| 删除卡片 | 详情页头部的垃圾桶（提示「删除卡片」） | 确认框「删除卡片「X」？相关关联也会一并移除。」→ 确定后卡片、它的标签关联、关联关系、图片链接、时间轴条目一并清理，地图标记与大纲节点上对它的引用会被置空，界面回到列表 |

### 4.13 右侧检查器：谁引用了我

选中卡片后，检查器标题变成「类型图标 + 卡片名」，从上到下：

| 区块 | 内容与操作 |
| --- | --- |
| 摘要 | 卡片的摘要；没写时显示「（还没有摘要）」 |
| `被文稿引用（N）` | 哪些正文 / 大纲提到了它；点一条直接跳到那篇文稿（没有时提示「还没有文稿提到它」） |
| `时间轴出场（N）` | 该卡片关联的时间轴条目；点一条跳到时间轴（没有时提示「还没有时间轴条目」） |
| `地图位置（N）` | 在哪些地图上被标了点；点一条跳到地图（没有时提示「还没有在地图上标记」） |
| `被关联（N）` | 有哪些卡片指向它；点一条跳到来源卡（没写关系名的显示「相关」） |
| 底部 | `创建 {日期}` + 置顶按钮 |

### 4.14 全局搜索

在顶栏搜索框里输入 → 卡片库的网格实时过滤，匹配范围包括标题、摘要、正文与字段值。清空搜索：点搜索框右侧的 `×`，或按 `⌨ Esc`。

## 5 地图

进入方式：点图标导航栏 `地图` 或按 `3`。地图用来表达方位、政区与资源分布，**一张地图 = 一个时期**。

### 5.1 界面分区

| 区域 | 内容 |
| --- | --- |
| 左栏 | 地图列表（每行显示地图名与时期）→ 新建地图输入框 → 当前地图的属性表单（名称 / 时期标签 / 对应刻度 / 底图 / 底图不透明度）→ `绘制工具` → `区域（N）` → `显示选项` → 底部灰字「标记 N · 区域 N」 |
| 中栏 | 顶部信息条「地图名 · 时期 · 标记 N · 区域 N」+ 右上三个按钮 `打点模式`、`选择`、`新建区域`；下面是画布 |
| 右栏 | 检查器，标题随选中对象变化：`地图概览` / `标记点` / `区域 / 资源` |

### 5.2 新建一张地图并上传底图

1. 左栏输入框里填名称（占位「新地图名称，如「245 年疆域」」）→ 按 `Enter` 或点右侧的 `+`（提示「新建地图」）。
2. 新地图立刻出现在列表里并被选中，右下角提示「已创建地图「245 年疆域」」，右栏显示「地图概览」。
3. 左栏属性表单里点 `上传底图` → 选择一张图片作为底图 → 提示「底图已更新」，按钮变成 `更换底图`，旁边出现「移除底图」。
4. 需要时拖动「底图不透明度 N%」滑块（20~100，步长 5），让标记更清楚。
5. 顺手填「时期标签」（占位「第三纪元 200 年」）与「对应刻度」（占位「可空」）——时期标签会显示在地图列表与顶栏信息条上，便于做「时期对比」。

> 没上传底图也能用：画布下方会提示「未设置底图 —— 可直接摆放标记点，之后在左侧上传底图不会错位」。
> 一张地图都没有时，中栏显示「还没有地图」+「在左侧新建一张地图。一个世界观可以有多张地图，用来表现不同时期的疆域与资源变化。」

**删除地图**：鼠标移到左栏地图行 → 行尾出现垃圾桶 → 点击 → 确认框「删除地图「X」？其标记与区域会一并移除。」

### 5.3 打点与移动标记

1. 点中栏右上角的 `打点模式` → 画布光标变成十字。
2. 在画布上想放标记的位置**单击** → 落下一个标记点，工具自动切回 `选择`，该标记被选中，右栏标题变成「标记点」。
3. 移动：用 `选择` 工具**按住标记点拖动**即可（坐标限制在 0~1 之间，不会拖出画面）。
4. 鼠标悬停在标记点上会显示提示：第一行是标记名称，第二行是备注。
5. 删除：选中标记后，右栏底部点 `删除标记`。

### 5.4 标记的属性与绑定卡片

右栏「标记点」表单（改动自动保存）：

| 字段 | 说明 |
| --- | --- |
| 标记名称 | 显示在图上（需打开「显示名称标签」） |
| 图标（emoji） | 直接填一个 emoji，如 `🏰` |
| 颜色 | 标记圆点的颜色 |
| X（0~1）/ Y（0~1） | 归一化坐标；直接改数字也能精确定位 |
| 备注 | 说明文字，鼠标悬停时显示 |
| `绑定卡片` / `更换卡片` | 把标记挂到一张设定卡上：点它 → 弹窗「把标记绑定到哪张卡片？」→ 搜索（占位「搜索卡片标题 / 摘要」）→ 点卡片即绑定；已绑定时显示卡片行与类型徽标 |
| `解绑` | 解除与卡片的绑定（标记本身保留） |
| `删除标记` | 删除这个标记 |

> 绑定卡片后，那张卡片的右侧检查器里就会出现「地图位置（N）」，点一下能直接跳回这里。

### 5.5 区域多边形与顶点编辑

1. 点中栏右上角的 `新建区域`（或左栏 `区域（N）` 那一行右侧的 `新建区域`）→ 画布上出现一个默认的菱形区域，名称是「新区域 N」，计数 +1。
2. **单击区域**即选中它：描边加粗，并显示白色顶点手柄，右栏标题变成「区域 / 资源」。
3. 调整形状：按住白色顶点拖动；顶点不够就点右栏的 `加顶点`，想去掉就点某个 `顶点 i`（提示「点击删除该顶点（至少保留 3 个）」，只剩 3 个顶点时不能再删）。
4. 右栏还能改「区域名称」「颜色」「所属时期」（占位「如：245 年」）与「备注」，以及 5 项资源数值。「删除区域」在表单最下方。

> 画布上**不能手绘多边形**：轮廓一律靠拖动顶点来调整。

### 5.6 资源打分与热度着色

1. 选中区域 → 右栏填 5 项资源：`人口`、`农业`、`矿产`、`军力`、`商贸`（后四项是 0~100 的指数，鼠标停在字段名上会看到单位「万人」或「指数」）。
2. 让颜色替你说话：左栏 `显示选项` 里点开 `资源热度` → 出现「热度指标」→ 选 `人口`（或其它四项）。
3. 此时所有区域按该项数值着色：0 偏蓝、100 偏红，按**当前地图的最大值**归一化。换指标即换着色。
4. 只想要轮廓不想看填充：把区域着色切成 `轮廓`；想恢复纯色填充就切回 `填充`。

### 5.7 显示选项与绘制工具

| 控件 | 作用 |
| --- | --- |
| `绘制工具` 里的 `选择` | 点选地图上的标记或区域进行编辑；点空白处取消选中 |
| `打点模式` | 在空白处点击即落一个标记点 |
| `区域` | 切换区域工具（当前版本只切换光标状态，区域请用 `新建区域` 按钮创建） |
| `平移` | 预留功能，当前版本尚未实现拖动整张画布 |
| `显示名称标签` | 开关：是否在图上显示标记名与区域名 |
| `区域着色`：`填充` / `轮廓` / `资源热度` | 区域的着色方式 |
| `热度指标` | 选 `资源热度` 后出现的 5 个指标按钮 |

### 5.8 右栏「地图概览」在看什么

未选中任何标记 / 区域时，右栏显示：

- 提示「点击地图上的标记或区域即可编辑」。
- `对比指标`：各区域的资源对比条形图（没有数据时提示「还没有区域数据」）。
- `本图区域排行`：按资源排序的区域列表。
- `跨地图时期对比`：把多张地图的数据放在一起比较（没有可比数据时提示「还没有可对比的数据」）。要让它有意义，就给每个关键时期建一张地图并填好「时期标签」。
- 底部还有一段引导文字，说明如何用「时期标签」串起不同时期的地图。

### 5.9 地图与时间轴的关系

当前版本**不做按刻度的自动联动**：

- 地图上的「对应刻度」只是记录下来备用。
- 想让时间轴条目指向地图：在时间轴条目的编辑器里用 `关联地图` 下拉选择某张地图；选中后，游标停在那个时刻时，「此刻正在发生」面板里会显示地图名。

## 6 时间轴

进入方式：点图标导航栏 `时间轴` 或按 `4`。时间轴把事件、角色生命线、地理与科技变化放在同一条数值刻度上。

### 6.1 界面分区

| 区域 | 内容 |
| --- | --- |
| 左栏（标题 `时间轴`） | `适配全部条目`、`从卡片生成` → `泳道（N）` → `纪元分段` → `时间单位`；底部说明「刻度是纯数值（可为负），显示时套用上面的单位名，例如 245 →「245 年」。」 |
| 中栏状态条 | `可见区间 100 → 400 年`、`· 条目 12`、`· 游标 245 年`；右侧 `放大`、`缩小`、`适配全部条目`、`清除游标` |
| 中栏主体 | 顶部是刻度尺（纪元色带 + 刻度），下面是各条泳道 |
| 右栏 | 未选中条目时是 `时刻快照`；选中条目后变成 `时间轴条目` |

### 6.2 第一步：先建一条泳道

时间轴的每类内容各占一条「泳道」。

1. 左栏 `泳道（N）` 区域下方有一个输入框，占位「新泳道名称」→ 输入名字（如「主线事件」）。
2. 旁边的类别下拉选一种：`事件`、`角色生命线`、`地理变化`、`科技水平`、`底层设定`、`势力`、`自定义`。下拉下方会显示该类别的说明，例如选「角色生命线」时提示「按出生/死亡刻度推算年龄与状态」。
3. 点输入框右侧的 `⊕`（或直接按 `Enter`）→ 泳道出现在下方列表里，右侧显示它的条目数 `0`。

泳道行上还能做这些事（鼠标悬停才显示图标）：

| 图标 / 控件 | 提示 | 作用 |
| --- | --- | --- |
| 眼睛 | `显示该泳道` / `隐藏该泳道` | 暂时不画这条泳道（数据保留） |
| 取色器 | `泳道颜色` | 改泳道配色：名称方块、条目条块、数值折线一起换色 |
| 泳道名 | — | 直接点进去改名字 |
| 垃圾桶 | `删除泳道` | 确认框「删除泳道「X」及其 N 个条目？」→ 连条目一起删除 |

角色生命线泳道下方还会显示推算结果，如 `游标时 32 岁`；没填字段时显示 `未填出生刻度` 或 `未绑定角色卡`。标记为数值型的泳道（科技水平等）名字下方带一个 `数值型泳道` 标签。

### 6.3 第二步：条目从卡片生成（当前唯一的生成方式）

时间轴条目不是手写出来的，而是**从卡片生成**——这样设定卡与时间轴永远是同一份数据。

1. 点左栏的 `从卡片生成` → 弹出对话框 `用哪张卡片生成时间轴条目？`。
2. 搜索并点一张卡片（可搜「事件」卡、「角色」卡、「势力」卡、「地点」卡）。
3. 生成的规则：
   - `事件` 卡 → 用它的「开始刻度 / 结束刻度」生成条目，落在类别为「事件」的泳道里。
   - `角色` 卡 → 用「出生刻度 / 死亡刻度」生成生命线条目，落在「角色生命线」泳道里。
   - 势力 / 地点卡 → 以刻度 0 生成，之后再手动改。
4. 常见提示：
   - 事件卡没填开始刻度 → 「该事件卡还没有填写「开始刻度」」，不生成。
   - 角色卡没填出生刻度 → 「该角色卡还没有填写「出生刻度」」，不生成。
   - 一条泳道都没有时点这个按钮 → 「请先创建一条泳道」。

> 当前版本**一次只能生成一条**，没有批量生成；也没有「手工新建空条目」的入口。

### 6.4 编辑一条条目

点画布上的条块（有起止）或菱形（瞬时）→ 右栏切成 `时间轴条目`：

| 字段 / 控件 | 说明 |
| --- | --- |
| `条目标题` | 显示在条块上的文字 |
| `所属泳道` | 下拉换到别的泳道 |
| `开始刻度` / `结束刻度` | 数值；结束刻度占位写「留空 = 瞬时」 |
| 时长短语 | 刻度下方自动显示「瞬时事件」或「持续 N 个刻度单位」；结束早于开始会追加「（结束早于开始）」提醒 |
| `该时段的状态 / 身份` | 占位「如：骑士团末席（受控）」；游标经过时会作为该角色的状态显示 |
| `备注` | 悬停条目时的提示文字 |
| `数值（科技 / 水平）` | 占位「0~100」，数值型泳道用它画折线 |
| `关联地图` | 下拉含 `（无）` 与各张地图名；关联后游标停在此时刻会显示地图名 |
| `关联卡片` / `更换卡片` / `解绑` | 把条目挂到设定卡上（对话框标题「关联到哪张卡片？」）；已关联时显示卡片槽，点卡片槽会跳到那张卡 |
| `删除条目` | 底部红色按钮，点击即删 |

改动都是自动保存（失焦 / 停止输入约 0.4 秒）。

### 6.5 拖动游标：某个时刻发生了什么

1. 在**刻度尺上按住左键左右拖动** → 出现竖向游标线与刻度气泡；各泳道同步画出细游标线。
2. 中栏状态条出现 `· 游标 245 年`。
3. 右栏 `时刻快照` 显示三块内容：
   - `当前时刻` 卡片：`245 年`。
   - `角色状态（N）`：每个角色一行，显示 `32 岁`；超过死亡刻度的显示 `已故`；无法推算的显示 `—`（一条角色泳道都没有时提示「没有可推算年龄的角色泳道」）。
   - `此刻正在发生（N）`：覆盖该时刻的所有事件，点任意一行即跳到该条目的编辑（没有事件时提示「此刻没有事件」）。
4. 点中栏的 `清除游标` 回到空态（提示「拖动刻度尺选择时刻」）。

### 6.6 视野操作

| 控件 | 作用 |
| --- | --- |
| `放大` / `缩小` | 以游标（没设游标时以视野中心）为锚点收窄 / 放宽可见区间 |
| `适配全部条目` | 把所有条目一屏装下（留 8% 边距）；左栏也有一个同名按钮 |
| 在刻度尺上滚动鼠标 | 只做**横向平移**（左右移动视野） |

> 画布上没有双击、右键菜单，也不能拖着条目改刻度——刻度请在上面的字段里改。

### 6.7 纪元分段（大时代背景色带）

1. 左栏 `纪元分段` 右侧点 `纪元` → 新增一张名为 `新纪元` 的纪元卡（起止刻度默认取世界观设置里的默认起止）。
2. 卡里可以改：名称、起止刻度（改完自动按起始刻度排序）、取色器 `纪元色`。
3. 效果：刻度尺顶部出现该颜色的色带，泳道区域出现同色的半透明背景带；鼠标悬停色带显示「名称（起 → 止） · 备注」。
4. 删除：卡上的 `删除纪元` 图标，点击立即删除。
5. 一个纪元都没有时，区域里提示「还没有纪元分段。加上之后，时间轴会用背景色带标出各个大时代。」

### 6.8 时间单位

左栏 `时间单位` 里有两个输入框（失焦生效）：

| 字段 | 默认 | 作用 |
| --- | --- | --- |
| `单位名` | `年` | 所有刻度文案都会带上它（`245 年`、`游标 245 年`） |
| `零点称呼` | `纪元元年` | 记录在案；**当前版本的刻度渲染还没有用到它**（已知缺口，见 [§14](#14-v01-的已知边界)） |

> 刻度本身是纯数值，可为负。所以「公元前 120 年」直接写 `-120` 即可。

## 7 写作

进入方式：点图标导航栏 `写作` 或按 `5`。这里写正文，并且**写到哪、设定就跟到哪**。

### 7.1 界面分区

| 区域 | 内容 |
| --- | --- |
| 左栏（标题 `文稿`） | 顶部 `+`（提示「新建文稿」）+ 类别切换 `正文` / `大纲` / `笔记` → `N 篇` 列表 → 底部 `快速新建` |
| 中栏 | 文稿标题输入框（占位「文稿标题」）+ `N 字`；右侧页签 `纯文本` / `分栏` 与专注写作按钮 |
| 中栏主体 | Markdown 编辑区；切成 `分栏` 后右侧出现实时预览列 |
| 右栏（标题 `相关设定`） | 本篇的标题结构、正文提到的卡片、待创建的引用 |

一篇文稿都没有时，中栏显示「还没有正文文稿」+「在左侧新建一篇正文，然后在写作时用 [[ 引用设定卡片。」+ 按钮 `新建正文`。

### 7.2 新建与切换文稿

1. 点左栏标题栏的 `+`（提示「新建文稿」）→ 按当前类别新建一篇（正文默认叫 `新正文`，笔记叫 `新笔记`）。
2. 或者在左栏底部 `快速新建` 输入框里填标题（占位「输入标题后回车」）→ 按 `Enter` → 直接建好并打开。
3. 切换类别：点左栏首行的 `正文` / `笔记` 按钮切换列表；点 `大纲` 会**跳到大纲模块**（大纲不在写作模块里编辑）。
4. 重命名：左栏列表里直接点标题改（失焦保存），或改中栏顶部的标题框。
5. 删除：鼠标移到左栏文稿行 → 行尾出现垃圾桶 → 确认框「删除文稿「X」？」。

### 7.3 写作区

| 控件 | 作用 |
| --- | --- |
| 标题输入框（占位「文稿标题」） | 改这篇文稿的标题 |
| `N 字` | 实时字数 |
| 页签 `纯文本` | 只看编辑区，适合沉浸写作 |
| 页签 `分栏` | 左边编辑、右边实时预览（预览用 0.4 秒去抖，打字时不会卡） |
| 专注写作（提示「专注写作」/「退出专注模式」） | 收起导航栏、侧栏、检查器；再点一次恢复 |
| 编辑区（占位「开始写作…输入 [[ 可引用设定卡片；提到已存在的卡片标题会自动变成可悬停预览的双链」） | Markdown 编辑，工具条与卡片正文完全一致（见 [§4.6](#46-正文支持的-markdown-与工具条)） |

> 写作模块**没有独立的「预览」页签**：想看渲染效果就切到 `分栏`。

### 7.4 在正文里插图

三种方式都行，效果一样（图片存进本地资源库，正文里写成 `![名字](asset:资源id)`）：

1. 工具条上的 `插入图片（也可直接粘贴 / 拖入）`；
2. 在编辑区直接 `⌨ Ctrl+V` 粘贴截图 / 复制的图片；
3. 把图片文件拖进编辑区。

完成后右下角提示「图片已插入并存入本地资源库」。

### 7.5 双链：把设定卡写进正文

1. 输入 `[[` → 弹出 `插入设定卡引用` 候选框。
2. 继续打字过滤 → 按 `⌨ Enter` 插入第一条匹配（用鼠标点也可以）。
3. 没有匹配时点 `新建「你输入的词」` → 以「概念」类型建卡并插入引用。
4. 切到 `分栏` 预览：正文里出现的卡片标题都会变成带下划线的链接，鼠标悬停浮出卡片摘要，点一下跳到那张卡。
5. 正文里只要提到已存在的卡片标题，也会**自动**变成这样的链接（标题长度 2~40 字才会自动关联；代码块、链接、已有双链内部不会重复处理）。

### 7.6 右栏「相关设定」

| 区块 | 内容与操作 |
| --- | --- |
| 顶部统计 | `N 字 · 约 N 分钟 · N 个标题` |
| 两个切换图标 | `显示本篇标题结构` / `显示相关设定`——在「标题结构」与「相关设定」两个视图之间切换 |
| `标题结构` | 本篇用 `#` 写出的标题树；还没写标题时提示「还没有标题」+「用 # 号写标题，这里会实时生成结构。」 |
| `相关设定（N）` | 正文里提到过的卡片清单；点一行跳到那张卡，鼠标悬停弹出卡片预览。一条都没有时提示「正文里还没有提到任何卡片。试试输入 `[[` 唤起卡片选择。」 |
| `待创建的引用（N）` | 写了 `[[标题]]` 但卡片还不存在的条目；点后面的 `建卡` 立刻以「概念」类型建卡 |
| 底部提示 | 「写到哪，设定就跟到哪。正文里出现的卡片标题会自动出现在下面。」 |

### 7.7 从写作切到大纲

左栏点类别按钮 `大纲` → 直接跳到大纲模块，那篇大纲的文本 / 树形 / 思维导图三种视图都在那里（见下一节）。

## 8 故事大纲

进入方式：点图标导航栏 `大纲` 或按 `6`。同一份大纲有**三种视图**，随时互切。

### 8.1 界面分区

| 区域 | 内容 |
| --- | --- |
| 左栏（标题 `故事大纲`） | `+`（提示「新建大纲」）→ 大纲列表 → `完成度` → `文本 ⇄ 树形` → `状态图例` |
| 中栏顶部 | 标题输入框、`N 个节点 · 完成 P%`、页签组 `编辑`／`分栏`、视图页签组 `文本`／`树形`／`思维导图` |
| 中栏主体 | 当前视图；`分栏` 时左侧编辑、右侧预览 |
| 右栏 | 与写作模块相同（标题结构 / 相关设定） |

一篇大纲都没有时，中栏提示「还没有大纲」+「大纲可以直接当 Markdown 写，也可以切成树形或思维导图。」+ 按钮 `新建大纲`（这个按钮建出来的叫「主线大纲」）。

### 8.2 三种视图

| 视图 | 怎么用 |
| --- | --- |
| `文本` | 像写文档一样用 Markdown 写大纲：`#` 第一幕、`##` 场景、`-` 关键节点。编辑区占位字是「# 第一幕 ## 开场 - 关键节点…」 |
| `树形` | 每个标题变成一个节点卡片，可挂卡片、切状态、升降层级。顶部提示「点击色块切换状态」「· 悬停节点显示操作」，底部有 `添加根节点` |
| `思维导图` | 同一棵树画成放射状导图；点节点即选中，下方出现状态按钮（`构思` / `写作中` / `已完成` / `已废弃`）与关联卡片按钮 |

### 8.3 树形视图的节点操作

鼠标悬停在节点上会出现一排图标：

| 图标（悬停提示） | 作用 |
| --- | --- |
| `添加子节点` | 在节点下加一个子节点 |
| `上移` / `下移` | 在同一层级里换位置 |
| `提升层级` / `降低层级` | 变成上一级的兄弟 / 变成上一级的子节点 |
| `挂接卡片` | 弹出「把大纲节点挂接到哪张卡片？」，选中即把节点与设定卡绑定 |
| `删除节点` | 直接删除（无确认框） |

节点本身还能改：标题（直接编辑）、摘要（占位「补充说明…」）、状态（点左侧色块循环切换，提示形如「状态：写作中（点击切换）」——四种状态与颜色见左栏 `状态图例`）。

树是空的时提示：「还没有节点。可以「添加根节点」，或在侧栏用「文本标题重建大纲树」一键生成。」

### 8.4 文本 ⇄ 树形 双向同步

这两步是**手动触发**的，用来把两种写法对齐：

| 左栏按钮 | 作用 | 结果 |
| --- | --- | --- |
| `用文本标题重建大纲树`（提示） | 按 Markdown 标题重新生成整棵树 | 提示「已从正文同步 N 个大纲节点」；正文里没有任何标题时提示「正文里没有找到 Markdown 标题（# / ## / ###）」 |
| `把大纲树写回文本`（提示） | 用树结构覆盖文本视图 | 提示「大纲树已写回文本视图」 |

> ⚠️ 两个方向都是**覆盖式**的：重建树会按标题重排（手写的节点摘要、状态、挂接的卡片以标题为准重建），写回文本会覆盖正文排版。想保平安就先存一个版本快照（见下一节）。

### 8.5 新建与删除大纲

- 新建：左栏 `+`（提示「新建大纲」）→ 建出一篇名为 `新大纲` 的文稿（类型是大纲）。
- 删除：鼠标移到左栏某一行 → 行尾出现垃圾桶 → 确认框「删除大纲「X」？」。

## 9 版本与对比

进入方式：点图标导航栏 `版本` 或按 `7`。它的用途是「改之前先存一份，改完看差在哪」。

### 9.1 存一个版本快照

1. 左栏点 `保存当前设定为版本`（图标按钮的提示是「保存当前设定为快照」）。
2. 版本名自动取当前时间（形如 `快照 2026/2/14 10:30:00`），右下角提示「已保存版本「快照 …」」。
3. 也可以用命令面板：`⌨ Ctrl+K` → 输入「快照」→ 选 `保存设定快照`。

左栏有一段说明值得一读：「快照包含卡片、标签、关联、地图、时间轴与文稿。图片二进制不进快照，因此体积很小。」

> 还没有快照时，列表位置提示：「还没有快照。建议在每次大改设定之前先存一个版本，之后就能对比出差在哪。」

### 9.2 看差异

1. 在左栏点一个版本 → 中栏显示 `版本名` + `vs 当前设定` + 保存时间。
2. 顶部汇总结论：`共 N 处差异`，下面分别给出 `新增卡片 n`、`删除卡片 n`、`修改卡片 n`、`关联 ±n`、`时间轴 ±n`。
3. 详情分五个**可折叠**区块：`新增卡片`、`删除卡片`、`修改卡片`、`文稿改动`、`其它变化`。点标题栏即折叠 / 展开。
4. 每个具体改动都带标记：`新增` / `删除` / `修改`；卡片会列出**字段级**变化（带字段名徽标）；文稿改动是**行级 diff**（标题处显示 `+n -n`，新增行 `+ 新增文稿《标题》`，删除行 `- 删除文稿《标题》`）。
5. 快照与当前完全一致时提示：「与当前设定完全一致」+「保存这个快照之后没有任何改动。」

### 9.3 还原

1. 选中版本 → 中栏点 `还原`。
2. 确认框：「用「X」覆盖当前设定？当前未保存的改动会丢失。」
3. 确定后当前设定被快照覆盖，提示「已还原到「X」」。

> 还原前软件会自动为当前状态存一份「临时快照（自动）」，所以手滑了还能找回来。

### 9.4 导出 / 删除单个快照

| 操作 | 位置 | 结果 |
| --- | --- | --- |
| 导出 | 版本行上的下载图标 | 得到一个 `版本名.snapshot.json` 文件 |
| 删除 | 版本行上的垃圾桶图标 | 确认框「删除版本「X」？」 |

### 10.2 装一个插件

1. 点左栏的 `载入插件`（左栏按钮或标题栏的 `↑` 图标）→ 弹出「载入插件」对话框。

4. 点 `载入并启用` → 装好并立即生效，右下角提示「插件「X」已载入」。
5. 对话框底部有一条**必读**的安全提示：「安全提示：v0.1 的插件与主程序运行在同一环境，能读写你的全部设定数据。请只载入你自己编写的或完全信任来源的插件。」

| --- | --- | --- |

### 10.4 插件设置

1. 在 `插件详情与设置` 里找到目标插件的卡片（**只有启用状态才显示设置表单**）。
2. 展开 `插件设置` → 按插件声明渲染出的控件直接改（开关 / 数字框 / 取色器 / 下拉 / 文本框）。
3. 改完**立即生效**，不需要停用再启用（例如内置「图库灯箱」的三项开关，改完下一次打开图片就是新行为）。

### 10.5 查看源码

每张详情卡底部有可展开的 `查看插件源码`，点开就是该插件的完整 JS 源码——安装前先读一遍，是这个「可信任插件」模型下最实用的安全手段。

### 10.6 图库灯箱（点击放大预览）

这是内置插件 `图库灯箱` 提供的功能，**默认已启用**。

**怎么用**

1. 打开任意一张卡片（卡片 Wiki → 点卡片 → 右列 `结构化字段` → 页签 `图库`）。
2. 点图库里任意一张缩略图 → 全屏放大预览出现：顶部一行显示图片说明与计数（如 `2 / 3`），中间是大图。
3. 切换图片（同属这张卡片的图会自动成组）：
   - 键盘 `←` `→`（也可以用 `PageUp` / `PageDown` / 空格）；
   - 点画面两侧的 `‹` `›` 按钮；
   - 默认**首尾循环**：在最后一张按 `→` 回到第一张。
4. 缩放：滚轮上下滚（或用 `+` / `-` 键），顶部计数右侧会显示倍率（如 `2 / 3 · 240%`）；双击图片或按 `0` 复位到「适应窗口」。
5. 关闭：按 `Esc`，或点击图片周围的空白处。

**三项设置**（插件 → 图库灯箱 → 插件设置）

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `两侧箭头与计数` | 开 | 多图时是否显示切换箭头与 `3 / 8` 计数 |
| `首尾循环切换` | 开 | 关掉后，在最后一张按 `→` 不再绕回第一张 |
| `滚轮缩放` | 开 | 关掉后滚轮不再缩放，避免误触 |

**它的边界（都是刻意的）**

- 只有**图库里的图片**参与放大：卡片瓦片上的封面、地图底图都不参与，这样点封面仍然是「打开这张卡片」。
- 卡片正文 / 文稿里插入的图片暂不参与（见 [§14](#14-v01-的已知边界)）。
- 不需要这个功能就在插件模块把它停用，界面立刻恢复原样，不留残余。

## 12 数据、保存与备份

### 12.1 自动保存是怎么工作的

- 任何一次修改都会打上「待保存」标记，**停止操作 0.8 秒后**自动写入本地数据库；不需要点保存。
- 页面切到后台 / 关闭标签页 / 关闭应用窗口时，会强制立刻落盘。
- 想手动确认：按 `⌨ Ctrl+S`（或命令面板里的 `立即保存到本地`）→ 右下角提示「已保存到本地」。
- 底部状态栏如实显示：`本地优先 · 数据仅存于本机`（还没写过）、`正在写入本地…`、`已保存 · 3 分钟前`、`保存失败：…`。

### 12.2 数据存在哪

三层，全在本机：

1. **内存里的 SQLite**（sql.js + WASM）：所有结构数据（卡片、标签、关联、地图、时间轴、文稿、版本、插件）。
2. **IndexedDB**（浏览器数据库）：定期落盘的整库二进制快照 + 图片二进制（图片单独存，SQLite 里只留元数据）。
3. **localStorage**：只有界面偏好（主题、布局、字号等）。

### 12.3 导出（设置 → 数据）

| 按钮 | 得到的文件 | 说明 |
| --- | --- | --- |
| `导出设定（JSON，不含图片）` | `世界名.settings.json` | 纯文本设定，体积小，适合进 Git / 传阅 |
| `导出完整备份（含图片，体积较大）` | `世界名.full.json` | 含全部图片二进制，换机器用它 |
| `导出 SQLite 原始数据库` | `世界名.sqlite` | 原始库文件，可用任何 SQLite 工具打开 |
| 版本页的下载图标 | `版本名.snapshot.json` | 只导出某一个版本快照（见 §9.4） |

**保存位置由谁决定**（设置页里也写着当前是哪种）：

- **桌面版**：点了导出会弹出系统的「另存为」对话框，**目录和文件名都由你选**；保存成功后提示会带上完整路径，例如「设定已保存到：D:\我的设定\猫猫的冒险.settings.json」。
- **网页版**：浏览器不允许网页指定保存路径（这是浏览器的安全限制，不是本应用的限制），文件会进入**浏览器的下载目录**。想换位置就在浏览器设置里改下载目录，或下载时选择「另存为」；提示会写「已交给浏览器下载（位置见浏览器的下载记录）」。
- 桌面版在对话框里点「取消」会提示「已取消导出」，不会产生文件。

导出完成后按钮上方会显示 `上次导出：{时间}`。

### 12.4 导入

1. `设置 → 数据` → `选择备份文件导入` → 选一个 `.json`（`settings.json` 或 `full.json` 都行）。
2. **先检查文件**：不是 WorldForge 的备份会提示「文件格式不正确：需要 WorldForge 导出的 JSON 备份」；备份里数据段缺失、或一张卡片都没有，会提示「这份备份不可用：…」并列出具体原因；文件超过 128 MB 会直接拒绝（基本上是内嵌图片太大）。
3. **确认框会写清代价**（应用内对话框，不是浏览器原生弹窗），例如：

   > **请确认（不可撤销）**
   > 即将导入：世界观「猫猫的冒险」：48 张卡片、7 个标签、16 条关联、2 张地图、16 个时间轴条目、3 篇文稿
   >
   > 导入会覆盖当前世界观「X」的全部内容（现有 8 张卡片、1 张地图会被替换，此操作不可撤销）。
   >
   > `取消`　`导入并覆盖`

   如果这份备份是旧版本导出的（图片没有挂载信息），确认框里会多一行「注意：…图片不会出现在图库里」。
4. 成功后提示「导入完成：48 张卡片、16 条关联」。

**导入的七条保证**（数据安全相关的行为，出问题时先看这里）：

1. **原子**：整笔写入包在一个事务里。中途任何一步出错都整体回滚，不会留下「原数据被清空、新数据没写完」的半套状态。
2. **自校验**：写完后按世界观统计行数，与备份里的行数比对，不一致就抛错并回滚 —— 宁可导入失败，也不会假装成功。
3. **失败不静默**：失败会弹出错误提示，并明确写着「已回滚（你的数据没有被改动）」。
4. **是复制不是搬移**：导入会把所有实体的 id 换成新的，所以**导入别人的备份不会影响对方原来的数据**；同一份文件导两次也不会互相覆盖。
5. **图片按 id 合并**：图片二进制留在原处复用，不会重复膨胀。
6. **图库挂载一起走**：卡片↔图片的挂载关系（哪张图挂在哪张卡片上）也在备份里，导入后图库照常显示。
7. **世界观信息一起带过来**：简介、时间轴口径（刻度单位 / 零点称呼 / 默认区间）都会从备份里恢复。

> 导入仍然是**覆盖**当前世界观，不可撤销。做之前先 `导出完整备份` 是唯一稳妥的后悔药。
>
> 旧版本（0.1.0 早期）导出的备份里没有图库挂载信息：这类文件仍能正常导入（卡片、地图、文稿、图片二进制都在），只是图片不会出现在卡片图库里 —— 预检会在确认框里提前告诉你。

### 12.5 持久化存储：是什么、会不会有影响

**它只做一件事**：告诉浏览器「磁盘紧张时不要自动删掉本站的数据」。除此之外不改动任何东西 —— 不联网、不上传、不改系统设置、不占额外空间、对电脑本身没有副作用。

状态显示在 `设置 → 数据 → 本地存储`：

- **桌面版**：显示 `桌面版不适用`，并告诉你数据在应用自己的数据目录里（安装包版一般在 `%LOCALAPPDATA%\com.worldforge.desktop`）。这类数据不受浏览器清理策略影响，**不需要申请**。
- **网页版**：显示 `已授予` / `未授予` / `当前浏览器不支持`。

**为什么点了申请还是「未授予」**：这个开关的授予权在浏览器手里，**多数浏览器不弹窗询问**，而是按「站点参与度」自动判断（是否安装为 PWA、是否加书签、访问频率、是否授权过通知等）。所以点一次没通过是正常现象，不是出错。

**怎么提高拿到授权的概率**（设置页里点「怎么才能拿到授权？」也能看到）：

| 环境 | 做法 |
| --- | --- |
| Chrome / Edge（桌面） | 地址栏左侧图标 → 「网站设置」查看存储项；或先把本站「安装为应用」/ 加书签、多访问几次，再点申请。Chromium 通常在站点有一定参与度后自动授予。 |
| Chrome / Edge（手机） | 菜单 → 「添加到主屏幕」装成 PWA，用几次后系统会把它当常驻应用，清理时跳过。 |
| Firefox | 点「申请持久化存储」后**会弹窗询问**，选「允许」即可；也能在 `about:preferences#privacy` → 「Cookie 和网站数据」→「管理例外」里查看。 |
| Safari（macOS / iOS） | 不支持这个开关；把本站「添加到主屏幕」后，iOS 会给已安装的 PWA 独立存储，不会被「清除历史记录」连带清掉。 |

**最稳的保障仍然是定期导出备份**：就算浏览器清了数据，导入备份就能完整恢复。持久化存储是「降低概率」，备份是「可恢复」。

### 12.6 危险操作（不可撤销）

| 按钮 | 确认框文案 | 结果 |
| --- | --- | --- |
| `重建示例世界观` | 「重建示例数据会先删除当前世界观，确定继续？」 | 清掉当前世界观并写回示例数据，提示「示例数据已重建」 |
| `清空全部数据` | 「这会清空本机上全部世界观数据（插件与设置保留），且无法撤销。建议先「导出完整备份」。确定继续？」 | 清空所有世界观数据（插件与界面偏好保留），提示「已清空全部数据，正在重新初始化…」后自动重载界面 |

> 做这两件事之前，建议先 `导出完整备份`。
>
> 所有「确认框」都是应用内对话框（标题「请确认」，危险操作会标「不可撤销」并给确认按钮上红色），
> 而不是浏览器原生弹窗 —— 桌面版的原生弹窗需要额外权限，会被系统拒绝并报错，所以统一改成了应用内的。

## 13 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 改了代码 / 更新了版本，界面看起来没变化 | 正在运行的是旧的开发服务器或旧的窗口 | 关掉窗口，重新 `npm run tauri:dev`；浏览器里按 `Ctrl+Shift+R` 强制刷新 |
| 我把图片从资源库删了，它却还占着封面位置 | 旧版本留下的悬空引用（引用指向已经不存在的图片） | 已在当前版本修复：启动装载数据时会自动清掉这类悬空封面并落盘。重启一次应用即可生效 |
| 点卡片瓦片上的封面图，没有放大预览 | 设计如此：只有**图库里的图**参与放大，否则会抢走「点封面打开卡片」的操作 | 打开卡片 → 右列 `结构化字段` → `图库` → 点里面的图 |
| 正文 / 文稿里插入的图片点不开大图 | 当前只给图库接了放大预览 | 已知边界，见 [§14](#14-v01-的已知边界)；需要的话可按 [`插件开发指南`](插件开发指南.md) §3.4 的契约扩展到正文图片 |
| `[[` 候选框上写着「↑↓ 选择」，但按上下键没反应 | 提示语与实际实现不符：目前只实现了 `Enter` 插入第一条 | 用鼠标点选，或先多打几个字缩小范围再回车 |
| 时间轴里找不到「新建条目」按钮 | 条目只能由卡片生成，保证设定卡与时间轴是同一份数据 | 先建一条泳道 → 点 `从卡片生成` → 选卡片。事件卡记得先填「开始刻度」 |
| 地图上怎么画多边形？ | 不支持手绘 | 点 `新建区域` 生成默认形状，再拖白色顶点、用 `加顶点` / `顶点 i` 增删顶点 |
| 地图的 `平移` 工具点了没反应 | 预留功能，尚未实现 | 用画布滚动条 / 窗口滚动查看；或把底图缩小后再上传 |
| 大纲树改了，文本视图却没变（或反过来） | 两种视图是手动同步的 | 用左栏 `把大纲树写回文本` / `用文本标题重建大纲树`；注意两者都是覆盖式操作，先存快照更稳 |
| 还原版本后图片不见了 | 快照**不含图片二进制**，只含元数据 | 图片仍在资源库里，通常还原后就能正常显示；跨机器迁移请用 `导出完整备份（含图片）` |
| 插件装上了，但 `插件面板` 里是空的 | 该插件没有注册面板（有些插件只加命令或主题） | 看 `插件插口注册情况` 的徽标数字；只加命令的插件在 `⌨ Ctrl+K` 命令面板里找 |
| 改了插件设置好像没反应 | 极少数插件把设置读进了自己的缓存 | 当前版本设置是实时生效的；真遇到就在插件列表里把它「停用 → 启用」一次 |
| 在输入框里按数字键没有切换模块 | 设计如此：单键快捷键在输入框里不触发 | 先点到空白处，或用 `⌨ Ctrl+K` |
| 手机上侧栏和检查器不见了 | 窄屏下它们变成从边缘滑出的浮层 | 点顶栏对应的面板按钮调出 |
| 担心浏览器把数据清了 | 站点数据可能被系统回收（授予权在浏览器手里，多数浏览器不弹窗） | 见 §12.5：桌面版不需要申请，网页版可按环境提高授予概率；**最稳的是定期 `导出完整备份`** |
| 导出后找不到文件在哪 | 网页版只能交给浏览器的下载目录；桌面版才有「另存为」 | 桌面版点导出会弹系统对话框，提示里带完整路径；网页版请看下载记录（见 §12.3） |
| 导入提示「已完成」但数据没进来 | 0.1.0 早期安装包的缺陷（导入没有改写世界观归属、也没有校验） | 已修复并加了 46 项回归自测：现在失败会明确报错并回滚。**请用最新构建**：`npm run tauri:dev`，或重新打包安装包 |
| 导入后原世界观的数据跑到新世界观去了 | 早期版本复用同一批 id，导致 UPSERT 覆盖 | 已修复：导入会为所有实体生成新 id（复制而不是搬移），来源世界观不受影响 |
| 导出完整备份再导入，图库里没有图了 | 早期版本的快照没包含「图片挂在哪张卡片上」（card_assets），只存了图片本身 | 已修复：现在快照与备份都带着图库挂载，导入后图库照常显示。旧备份（0.1.0 早期导出的）仍可导入，但图库挂载无法恢复 —— 确认框会提前提醒 |
| 桌面版里点删除/清空，弹出「dialog.confirm not allowed. Command not found」 | 早期版本用的是浏览器原生 `confirm`，Tauri 会把它转发给 dialog 插件，而应用没有申请该权限 | 已修复：所有确认框改成应用内对话框（14 处调用全部替换）。需要重启 `tauri:dev` 或重新打包才能生效 |

## 14 v0.1 的已知边界

这些是**当前版本刻意不做或尚未做完**的部分，遇到时不必怀疑是自己操作错了：

**地图**
- 不做精细边界绘制与 GIS 投影，只做归一化标记与粗略多边形；不能在画布上手绘多边形。
- `平移` 工具是预留项，尚未实现；画布上没有滚轮缩放、双击、右键菜单。
- 地图与时间轴之间没有按刻度的自动联动，只能靠条目上的 `关联地图` 手动挂钩。

**时间轴**
- 刻度是数值而非真实历法换算；「零点称呼」目前只是记录，未参与刻度渲染。
- 世界观的「年龄换算系数」尚未被时间轴使用（年龄按刻度差直接计算）。
- 条目只能由 `从卡片生成` 产生，一次一条，没有批量生成，也不能拖着条目改刻度。
- 没有独立的「影响范围」字段，用 `关联地图` 代替。

**写作**
- 只有 `纯文本` 与 `分栏` 两种视图，没有独立的「预览」页签。
- Markdown 是自研子集：支持标题、列表、引用、代码、表格、链接、图片、双链与四种强调；不支持脚注、公式、HTML 内嵌、任务列表等扩展语法。

**卡片与图库**
- `[[` 候选框的「↑↓ 选择」尚未实现（只支持 Enter 插入第一条）。
- 卡片正文 / 文稿里的图片暂不支持点击放大（图库里的图片支持）。
- 图库不支持拖拽排序，缩略图顺序按添加时间。

**版本**
- 快照不含图片二进制，也不含 `plugins.code`；分支级 diff 的自动合并不做。

**插件**
- 插件无沙箱，与应用同源同权限运行，属于**可信任模型**：只装你自己写的或完全信任来源的插件。
- 插件只能通过 `PluginAPI` 与宿主交互；v0.1 没有「浮层插口」与「资源读取接口」，所以像图库灯箱这样的插件是靠在宿主标记过的 DOM 上做事件委托实现的。

**其它**
- 不做云同步、账号、多人协作；所有数据只在本机。
- 插件运行在同一环境，因此插件带来的稳定性风险由插件作者承担（载入与事件回调有 `try/catch` 兜底）。
