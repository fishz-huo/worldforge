## 1. 项目定位

**WorldForge（世界观工坊）**：本地优先（Local-First）的世界观构建 + 写作工具。

- 一句话价值：**轻量 Wiki + 零切换写作**，专门构筑作品的世界观与角色故事。
- 用户是**小说作者 / 游戏策划 / 跑团 GM**，共同点：脑子里有一整个世界，但讨厌为了"记设定"去学一套重型软件。
- 使用场景：一个人、一台电脑、一个长期项目。数据存在本机 IndexedDB，不联网、不上传、无需账号。
- 设计稿要传递的气质：**像一本自己整理得很好的工作笔记**——安静、可信、随时可翻。

### 1.1 对设计稿的表达纪律（重要）

- **不要拿别的软件作比较**（不写"比 XX 轻量""像 XX 那样"），画面与说明里都不出现第三方产品名。
- 不要出现本机路径、内网 IP、邮箱等个人信息；示例数据统一用原创世界观《潮线之外》。
- 不做"新手学不会"的谦卑叙事，也不自夸。画面上就是产品本身。

## 2. 设计原则（四条，冲突时按序号优先）

1. **轻量**——少即是多。能靠留白和层次区分的地方不要加边框，能靠一个图标说清的地方不要加按钮。同一屏内视觉焦点不超过 1 个。
2. **零切换写作**——写正文时设定就在旁边。任何"必须离开当前页面才能查到的信息"都要在稿子里体现出**浮层/侧栏就地预览**，而不是跳转。
3. **结构化但不笨重**——卡片有类型、字段、标签、关联，但界面上呈现为**可折叠的次级信息**，默认不喧哗（信息密度高、装饰密度低）。
4. **可维护**——所有可见件都必须来自既有组件库与既有 token。设计稿里出现的每一个元素，都要能在真实代码里找到出处。

## 3. 设计风格

### 3.1 整体基调

极简、专业、**有书卷气**。参考气质：Notion 的克制 + Arc Browser 的柔和圆角与低饱和层次。

具体表现为：

- 界面用**暖中性米色**打底（不是纯白、不是冷灰，是带一点暖的米白），唯一的强调色是**暖棕（primary）**，只在"当前/可点击/选中"处出现。
- 大量 `bg-card/40` 这类**半透明叠加**制造层次，而不是靠深色分隔条。
- 分隔线一律 **1px**，颜色极淡（`--border`）；不做粗边框、不做投影堆叠。
- 投影只用在"浮起来的东西"上：弹窗、抽屉、下拉菜单、悬浮卡片。平铺内容**不投影**。
- 圆角统一偏柔（9.6px 基准），没有 0 圆角的直角块，也没有胶囊化滥用。
- 动效只做 150–200ms 的透明度/位移过渡，不做弹跳、不做旋转。

### 3.2 亮色主题 token（暖中性 · 米色，HSL 分量 → 设计稿用 hex）

> **色板基调（2026-09-21 变更）**：整体从冷调雾蓝灰改为**护眼米色（暖中性）**——底色不再是纯白/冷白，而是带一点暖的米白，文字与描边同步转暖，避免"暖底冷字"的脏感。
> 换色前后对比度已按 WCAG 2.1 实测：正文 **17.8:1（AAA）**、次级文字对米底 **5.36:1（AA）**、对卡片底 **5.64:1（AA）**；暗色正文 **16.0:1（AAA）**、暗色次级 **6.99:1（AA）** —— 护眼不以牺牲可读性为代价。
> 色相统一落在 **H 37–43°（暖区）**且低饱和，这是"米"而不是"黄"的关键；不要自行调高饱和度。

- 侧栏悬停：`#EBE4D6`；选中：`#7A4A2E` 15%（`bg-primary/15`）+ 文字 `#7A4A2E`。

- 搜索命中高亮：`#DFAF57` 30%。
- 地图网格：`#E5DECF` 50%，网格尺寸 **40px × 40px**。
- 保存成功勾：`#4E9E7A`；置顶星：`#DFAF57`。
- 图片占位块：`#E8E1D2`，占位图标 `#A79C89`。

### 3.5 字体

```text
sans: Inter → system-ui → "Noto Sans SC" → "Microsoft YaHei" → sans-serif
mono: "JetBrains Mono" → Consolas → monospace
```

- **中文走系统字体**（思源黑体 / 微软雅黑），**西文与数字走 Inter**。设计稿里：字体名填 `Inter`，中文自然回退；不要给中文指定 Inter。
- 数字（刻度、字数、资源指数）**尽量用 Inter**，观感更稳。
- 字重只用三档：`400`（正文）、`500`（中等强调/按钮）、`600`（标题）。不用 700 以上的黑体字做界面标题。
- 不使用衬线体（书卷气靠留白和层次，不靠宋体）。

**字号阶梯（px / 行高）**——设计稿严格按此取，不要自造中间档：

| 用途 | 字号 | 行高 |
| --- | --- | --- |
| 微型标签、时间戳、标签文字、导航栏文字 | 10 | 14 |
| 名称列/卡片描述/状态栏/次级说明 | 11 | 16 |
| 面板标题、Tab 文字、表单标签、徽标 | 12 | 18 |
| 正文小字、按钮文字、卡片副标题行 | 13 | 20 |
| 卡片标题、按钮（默认）、模块标题 | 14 | 20 |
| Markdown 正文默认 | 15 | 28 |
| 弹窗标题 / 区块大标题 | 16 | 24 |
| 统计数字（"本机数据概览"里的数值） | 18 | 28 |
| 写作页文稿标题（编辑器内 H1） | 24 | 32 |

### 3.6 圆角

基准 `--radius = 9.6px`：

| 名称 | 值 | 用在哪 |
| --- | --- | --- |
| `sm` | 5.6px | 小标签、小按钮（`sm`/`icon-sm`）、kbd |
| `md` | 7.6px | 默认按钮、输入框、Tab 触发器、下拉项 |
| `lg` | 9.6px | 卡片、面板区块、弹窗、图片、代码块 |
| `full` | 999px | 色点、滚动条滑块、时间轴游标头 |

### 3.7 阴影（只在"浮起来"时用）

| 层级 | 值 | 用在哪 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px 0 rgb(0 0 0 / 0.05)` | 卡片、输入框、选中的 Tab |
| `shadow-md` | `0 4px 6px -1px rgb(0 0 0 / 0.1)` | 卡片 hover |
| `shadow-xl` | `0 20px 25px -5px rgb(0 0 0 / 0.1)` | 窄屏抽屉浮层 |
| 弹窗 | `shadow-lg` + 全屏遮罩 `#12100C` 40%（暗色下 `#000000` 60%） | Dialog |
| 选中环 | `0 0 0 1px #7A4A2E66` | 选中的卡片 |

平铺内容（列表行、面板区块、正文区）**不加阴影**。

### 3.8 间距与对齐

- 基础网格 **4px**；常用档位：`2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32`。
- 面板内边距：`8px`（顶栏、面板标题行 `px-2`）。
- 卡片内边距：`10px`，左侧因色条多留 `12px`（`p-2.5 pl-3`）。
- 卡片网格间距：`12px`；列表行间距：`4–6px`。
- 区块之间：`12–16px`；设置页大区块之间：`16px`。
- 正文编辑区左右留白：容器居中，最大宽 `768px`，上下 `16px`。
- **对齐铁律**：一行里的文字基线与图标中心对齐；图标尺寸只用 `12 / 14 / 16 / 20 / 24 / 40` 六档。

### 3.9 图标

- 图标库固定 **lucide-react**（`.pen` 里 `library: "lucide"`），线宽 2，圆头。
- 尺寸语义：`12px` 微型（Tab 内、状态栏）、`14px` 标准（按钮、列表）、`16px` 面板级、`20px` 空状态、`40px` 空状态大图。
- 图标默认色 = `--muted-foreground`；选中态 = `--primary`；危险 = `--destructive`。
- 不做多色插画图标。类型图标可以用 §3.4 的类型色。

### 3.10 交互状态规范（画稿必须体现的部分）

| 状态 | 表现 |
| --- | --- |
| hover | 底 `--accent`；描边类元素从 `--border` → `--primary/40` |
| 选中 / 激活 | 底 `--primary/15`、字/图标 `--primary`、左侧 2px `--primary` 指示条（导航栏用 2×20px 竖条） |
| 聚焦（键盘） | 1px `--ring` 环 + 1px offset |
| 禁用 | 透明度 50%，`cursor: not-allowed` |
| 危险操作 | 按钮 `--destructive` 实底；破坏性确认放在 Dialog 内，主按钮红、次按钮描边 |
| 保存状态 | 状态栏左端：写入中 = 旋转图标；成功 = `#34D399` 勾；失败 = `#DC2828` 警告三角 |
| 空状态 | 居中竖排：大图标 + 标题（14–16px/600）+ 一句说明（12px/`--muted-foreground`）+ 一个主按钮 |

## 4. 组件库约束

### 4.1 硬约束

1. **只能用仓库已有的组件**（下表）。设计稿里出现任何"新造的、和已有组件职责重复"的组件都算违规。
2. 图标只用 **lucide-react**。
3. 不允许为了好看引入：富文本工具栏、图表库风格的立体图表、渐变按钮、玻璃拟态、3D 卡片。
4. 设计稿里出现的组件，必须能在下表中找到一一对应项；找不到就先改设计，不要"新加一个组件"。

### 4.2 可用组件清单（`src/components/ui/`）

`Button`、`Input`、`Textarea`、`Label`、`Checkbox`、`Switch`、`Slider`、`Select`、`Card`、`Badge`、`Dialog`、`DropdownMenu`、`Tabs`、`Tooltip`、`Popover`、`ScrollArea`、`Separator`；
另有一组自研基础件（`primitives.tsx`）：`EmptyState`、`Progress`、`SectionTitle`、`FieldRow`、`Dot`。

### 4.3 尺寸与形态（照抄，不要重新设计）

**Button** —— 高度/内边距/字号固定：

| size | 尺寸 | 字号 | 备注 |
| --- | --- | --- | --- |
| `sm` | h 28px，px 8px | 12 | 工具条、次级操作 |
| `default` | h 32px，px 12px | 13 | 常规 |
| `lg` | h 40px，px 24px | 13 | 空状态主按钮、弹窗主按钮 |
| `icon` | 32 × 32 | — | 图标按钮 |
| `icon-sm` | 24 × 24，图标 14px | — | 顶栏、面板标题行 |

variant：`default`（紫底白字）、`destructive`（红底）、`outline`（透明底 + `--input` 描边）、`secondary`（`--secondary` 底）、`ghost`（无底，hover 出 `--accent`）、`link`（紫字下划线偏移 4px）。图标与文字间距 `6px`。

**Input** —— h 32px，px 10px，圆角 md，`--input` 描边，placeholder 用 `--muted-foreground`；顶栏搜索框为 h 28px、字号 12、左侧 14px 搜索图标、右侧清除按钮。
**Textarea** —— 同 Input 的边距与描边；卡片"一句话摘要"最小高 52px、字号 12。
**Label** —— 12px / 500 / `--foreground`。
**Checkbox** —— 16px 方，圆角 4px，选中紫底白勾。
**Switch** —— 28 × 16 胶囊（`h-4 w-7`，2px 透明描边内缩），滑块 12px 圆形、选中时右移 12px；选中轨道紫、未选中轨道 `--input`，滑块恒为 `--background` 白 + `shadow-lg`。
**Slider** —— 轨道高 4px（`h-1`）圆角 full、底 `--muted`；已填充段紫；滑块 12px（`size-3`）圆形，`--background` 底 + 1px `--primary` 描边 + `shadow`。
**Select** —— 触发器同 Input；下拉面板圆角 lg + `shadow-md`，项高 28px、字号 12，选中项左侧紫勾。
**Card** —— 白底 + 1px `--border` + 圆角 lg + `shadow-sm`；分区：Header p 12 / Title 14-600 / Description 12-`muted` / Content p 12 去掉上边距 / Footer 横向 gap 8。
**Badge** —— 高 20px，px 6px，字号 10–11，圆角 6px；`outline` 变体常用于分支徽标（无描边 + 分支色 13% 底 + 分支色字）。
**Dialog** —— 宽 480–560px，圆角 lg，p 16；标题 16-600、说明 12-`muted`；底部右对齐两个按钮（次按钮 outline + 主按钮 default/destructive）；遮罩 `#0F1729` 40%。
**DropdownMenu** —— 宽 ≥ 180px，项高 28px，字号 12，项内图标 14px + 文字 gap 8；分组标题 10px 大写感灰色；危险项红字；分隔线 1px。
**Tabs** —— `TabsList` 高 32px，底 `--muted`，圆角 md，内边距 2px，项间距 2px；`TabsTrigger` 高 28px、px 8px、字号 12；激活项 = 白底（暗色 `--card`）+ `shadow-sm` + `--foreground`；非激活 = `--muted-foreground`。内容区与列表间距 8–12px（`mt-3`）。Tab 内图标 12px，与文字 gap 4px。
**Tooltip** —— 深底（暗色更亮一档）+ 白字 11px + 圆角 6px + px 8py 4 + `shadow-md`，出现延迟短、150ms 淡入。
**Popover** —— 同 Select 面板：圆角 lg、`shadow-md`、p 10–12。
**ScrollArea / 细滚动条** —— 宽 10px，滑块圆角 full、色 `--border`，hover `--muted-foreground/40`，轨道透明。
**Separator** —— 1px `--border`，横竖皆可。
**EmptyState / Progress / SectionTitle / FieldRow / Dot** —— 空状态居中；Progress 为细条（高 4px）圆角 full、填充紫；SectionTitle 为 12px/600 小标题（可带右侧操作）；FieldRow 为"标签 100px 定宽 + 控件"的两列行；Dot 为 6px 圆点（用于标签色点）。

### 4.4 面板外壳（三栏的每一栏都长这样）

`SidePanel` / `InspectorPanel` 结构固定，设计稿照搬：

├─ 标题行：h 36px，px 8px，底边 1px --border
│   ├─ 标题：12px / 600 / 左对齐，超长省略

- 面板之间的分隔线**画在面板内部的 1px 渐变里**（视觉上等于 1px 线、但不占宽度）。设计稿：直接画 1px 直线即可，不要留 2px 缝。

## 5. 布局规范

### 5.1 骨架（桌面 ≥1024px）

```text
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏 44px：WorldForge v0.1 │ 模块名 · 提示词   [搜索框] [当前分支] │
│                                  [侧栏][检查器][专注][主题][命令]  │
├────┬──────────────┬────────────────────────────┬─────────────────┤
│导  │ 次级侧栏      │        主内容区             │   检查器         │
│航  │ 256px        │        flex-1              │   320px         │
│栏  │ (可拖拽)      │                            │   (可拖拽)       │
│56px│              │                            │                 │
├────┴──────────────┴────────────────────────────┴─────────────────┤
│ 状态栏 24px：✓ 已保存 · 刚刚 │ 卡片 28 │ 关联 16 │ 地图 1 │ 潮线之外 / 主世界 │
└──────────────────────────────────────────────────────────────────┘
```

- 顶栏内容：左 = 产品名（14px/600）+ 版本号（11px/muted）+ 竖分隔 + 模块名（12px/500）+ `· 提示词`（11px 常态灰）；中右 = 搜索框（最大宽 320px）；右 = 分支切换（`当前分支`/`全部分支`，仅 ≥1024 显示）+ 5 个图标按钮。
- 导航栏（`SideRail`）56px：9 个模块**竖排**，每项 `40×40` 圆角 md，内含 16px 图标 + 10px 文字；选中 = 底 `#7C3BED` 15% + 字/图标 `#7C3BED` + 左侧 2×20px 紫条（距左边 -6px）；底部 = 收起箭头 + 世界切换器（圆形世界头像）。
- 模块顺序固定：总览(`LayoutDashboard`) → 卡片 Wiki(`Boxes`) → 地图(`Map`) → 时间轴(`Timer`) → 写作(`FileText`) → 大纲(`ListTree`) → 版本(`GitBranch`) → 插件(`Puzzle`) → 设置(`Settings`)。
- 三栏高度都撑满（除顶栏与状态栏），各栏**独立滚动**，主内容区不整体滚动。
- 搜索框在「总览 / 插件 / 设置」三页**不显示**（顶栏右侧自动靠右）。

### 5.2 拖拽调整宽度

- 侧栏与检查器之间的边界各有一条**6px 隐形拖拽区**（视觉上仍是 1px 线，hover 时线变 `--primary/40`，光标 `col-resize`）。
- 拖拽范围：侧栏 192–480px，检查器 192–640px。
- **双击分隔线复位**回默认值（侧栏 256px、检查器 320px）。
- 宽度被记住，下次打开仍是用户拖过的宽度。
- 设计稿表现：其中一屏画"拖拽中"的样子——分隔线变紫、鼠标为左右箭头、被拖的那一栏略高亮。

### 5.3 窄屏与浮层（必须画出来）

| 断点 | 行为 |
| --- | --- |
| ≥1024px | 标准三栏并排，两条分隔线可拖拽 |
| 768–1023px | **检查器**变右侧浮层：宽 `min(设定宽度, 88vw)`，从右侧滑出，带 `shadow-xl`，背后有 `#0F1729` 20% + 1px 模糊的**背板**（scrim），点背板即关闭 |
| <768px | **侧栏也变浮层**（左侧滑出，同宽度规则）；底部出现 52px 标签栏（4 个高频模块 + 更多）；两个浮层**互斥**，同时打开时只留最新的一个 |
| 触屏 | 所有"只有 hover 才出现"的操作按钮改为**常显** |

- 窄屏浮层底部要空出底部标签栏高度，否则最后一行（常常是"删除"）点不到。
- 设计稿至少画一张 768×900 的"检查器浮层 + 背板"态。

### 5.4 特殊布局

- **时间轴**：横向信息为主，1024px 窗口下三栏只剩 448px 给画布，因此时间轴的"泳道与纪元"管理收进工具条的下拉浮层（`TimelineManagePopover`）。它的结构：单一横向滚动容器，内部第一个子元素是 **sticky 刻度尺**，名称列 `sticky left:0`。设计稿照这个结构画，**不要**把刻度尺画成独立横条浮在上面。
- **写作 / 大纲**：主内容区顶部有一条 h 36px 的标题条（标题输入 + 字数/节点数 + 右侧视图 Tabs），下面是编辑区（分栏时 1:1 两列，≥1024 才并排）。

## 8. `.pen` 生成技术约束

1. **颜色直接写 hex**：`.pen` 里的 `fill` 不支持 Tailwind 的 `hsl(var(--x))`，必须用 §3.2/§3.3 的 hex 值。
2. **分隔线用描边画**：真实实现把竖分隔线画在面板内部（不占宽度）。设计稿用 1px 描边（`strokeAlignment: inner`）表现，**不要**用 1px 实心矩形占位，否则三栏宽度会整体偏移。
3. **`lineHeight` 是倍数不是像素**：`lineHeight: 1.5` 表示 150%；写 `28` 会把布局放大 28 倍，直接崩。
4. **面板宽度用固定值**：侧栏 256、检查器 320、导航栏 56、顶栏 44、状态栏 24、面板标题行 36。主内容区用 `fill_container`。
5. **画板尺寸**：桌面 `1440 × 900`；窄屏态 `768 × 900`；手机态 `375 × 812`。画板底色 = `--background`。
6. **文字**：`textGrowth: "fixed-width"` 才能换行并让高度自适应；单行标签用 `auto`。省略号要手动截断文本，不要依赖溢出。
7. **图标**：`type: "icon"`，`library: "lucide"`，图标名用 §3.4 与 §5.1 里的英文名（`LayoutDashboard`、`Boxes`、`Map`、`Timer`、`FileText`、`ListTree`、`GitBranch`、`Puzzle`、`Settings`、`Search`、`Moon`/`Sun`、`Terminal`、`Focus`、`PanelLeft`、`PanelRight`、`PanelLeftClose`、`PanelRightClose` 等）。
8. **命名**：画板/顶层帧用 `WF-0x 名称 · 亮色`；层名用中文语义名（`顶栏`、`次级侧栏`、`卡片瓦片-选中`），便于对照代码。
9. **对齐**：所有间距落在 4px 网格；卡片网格列宽 220px 起、间距 12px；三栏宽度严格按第 0 节数字。

## 9. 文字与示例数据规范

- 界面文案一律**简体中文**，与代码里现有文案逐字一致（如「卡片 Wiki」「总览」「时间轴」「零切换正文编辑，悬浮预览设定卡」）。不要自创同义词。
- 示例世界观固定用原创的 **《潮线之外》**：世界名「潮线之外」，分支「主世界」；卡片示例（角色/地点/事件/势力/物品/概念/参考资料/随笔各一）如「潮线守望者」「沉钟港」「大退潮」「盐商行会」「回声螺」「潮汐律」「旧航海志」「一行边注」。
- 时间轴刻度用整数刻度（如 `-200 / 0 / 340 / 512`），纪元名如「远潮纪 / 沉钟纪 / 退潮纪」；角色年龄文案「游标时 34 岁」。
- 写作页示例正文用中文散文，并**至少出现两处 `[[沉钟港]]` 形式的双链**、一处 `[[不存在的锚点]]` 失效双链（带删除线的灰字）。
- 不要出现真实人名、真实机构、真实地名、邮箱、路径、IP。
- 数字与单位：字数「1,842 字」（千分位）、时间「3 小时前」「更新于 2026-09-21 10:16」、资源「人口 12.4 万」「农业 68」。
